# ⚡ ChillFetch

**ChillFetch** is a clean, modern, and ad-free web application that lets users fetch and download video content seamlessly across 7 major platforms:

- 📺 YouTube
- 📸 Instagram
- 🎵 TikTok
- 🤖 Reddit
- 👥 Facebook
- 🐦 X (Twitter)
- 📌 Pinterest

## 🛠️ Tech Stack
- **Backend:** Python, Flask, `yt-dlp`, Flask-CORS, Gunicorn
- **Frontend:** Vanilla HTML5, CSS3 (Glassmorphism & Particle Canvas), JavaScript (Fetch API)
